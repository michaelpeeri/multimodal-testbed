# Data requirements
1. Observations will ultimately have N=~20,000 counts, noisy and with many MAR/MNAR missing values.  
2. As a found
2. Preliminary evaluation is done using synthetic data on varying small scales. The synthetic data generation methods are developed alongside the models. Currently, the synthetic data is generated by make_synthetic_data5 (synthetic_data.py) using latents from random_points_on_hypersphere (sythetic_data.py)  
3. The latent is a low-dimensional manifold, with an unevenly spread prior, with high-likelihood regions surrounded by low-likelihood regions. All non-zero-likelihood regions are connected, but they might be connected by long narrow “corridors” (representing cell differentiation stages, etc). There are no inherent “classes” in the latent and it should be modeled as continuous, not categorical (any classification or clustering would be done downstream of the model). Preserving the prior structure and distribution is important for accurately representing samples.  
4. The main objective of the models is to infer the latent from noisy observations, while preserving the structure of the latent and avoiding mode collapse or distortion. A secondary objective might be to impute missing values (by accurately placing the incomplete sample in latent space).  
5. As a stepping stone, the models are used to evaluate different architectures and understand how to analyze their implicit biases, measure sample efficiency etc. Existing models are found in models.py  
6. The main requirements for the model are:  
  a. Representing the prior distribution of the latent while avoiding mode collapse  
  b. Inferring the latent from noisy and incomplete observations  
  c. High sample efficiency to allow training on biological data with p>>N, i.e. limited number of samples available (or even possible) but a large number of features per sample
